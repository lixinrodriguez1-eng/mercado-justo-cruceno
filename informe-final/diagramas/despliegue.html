Proceso de despliegue (CI/CD)

Del código local a la URL pública; los secretos viven solo en Vercel y en el .env local (nunca en GitHub)

1. Desarrollo local

Next.js + XAMPP. Pruebas funcionales, de seguridad y Lighthouse.npm run build

2. GitHub

Rama proyecto-final. .gitignore excluye .env*git push origin

3. Vercel build

npm install → prisma generate → next buildvariables: DATABASE_URL, AUTH_SECRET

4. Producción

Funciones + CDN con HTTPS y HSTShttps://…vercel.app

5. Verificación

36 pruebas HTTP, recorrido con Playwright y Lighthouse sobre la URL pública
